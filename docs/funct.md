## Круг

### circle.area(r)

Определена в модуле [circle.py](../circle.py)

```python
area(r)
```

Считает площадь круга по его радиусу.

Формула: S = π · r²

**Параметры**

| Имя | Тип | Описание |
|-----|-----|----------|
| `r` | число | радиус круга |

**Возвращаемое значение**

Площадь круга (`float`).

**Пример**

```python
>>> import circle
>>> circle.area(1)
3.141592653589793
```

### circle.perimeter(r)

Определена в модуле [circle.py](../circle.py)

```python
perimeter(r)
```

Считает длину окружности по её радиусу.

Формула: P = 2 · π · r

**Параметры**

| Имя | Тип | Описание |
|-----|-----|----------|
| `r` | число | радиус круга |

**Возвращаемое значение**

Длина окружности (`float`).

**Пример**

```python
>>> import circle
>>> circle.perimeter(2)
12.566370614359172
```

## Прямоугольник

### rectangle.area(a, b)

Определена в модуле [rectangle.py](../rectangle.py)

```python
area(a, b)
```

Считает площадь прямоугольника по двум соседним сторонам.

Формула: S = a · b

**Параметры**

| Имя | Тип | Описание |
|-----|-----|----------|
| `a` | число | длина первой стороны |
| `b` | число | длина соседней стороны |

**Возвращаемое значение**

Площадь прямоугольника.

**Пример**

```python
>>> import rectangle
>>> rectangle.area(3, 5)
15
```

### rectangle.perimeter(a, b)

Определена в модуле [rectangle.py](../rectangle.py)

```python
perimeter(a, b)
```

Считает периметр прямоугольника по двум соседним сторонам.

Формула: P = 2 · (a + b)

**Параметры**

| Имя | Тип | Описание |
|-----|-----|----------|
| `a` | число | длина первой стороны |
| `b` | число | длина соседней стороны |

**Возвращаемое значение**

Периметр прямоугольника.

**Пример**

```python
>>> import rectangle
>>> rectangle.perimeter(3, 5)
16
```

## Треугольник

### triangle.area(a, h)

Определена в модуле [triangle.py](../triangle.py)

```python
area(a, h)
```

Считает площадь треугольника по основанию и опущенной на него высоте.

Формула: S = a · h / 2

**Параметры**

| Имя | Тип | Описание |
|-----|-----|----------|
| `a` | число | длина основания |
| `h` | число | высота, опущенная на основание `a` |

**Возвращаемое значение**

Площадь треугольника (`float`).

**Пример**

```python
>>> import triangle
>>> triangle.area(10, 3)
15.0
```

### triangle.perimeter(a, b, c)

Определена в модуле [triangle.py](../triangle.py)

```python
perimeter(a, b, c)
```

Считает периметр треугольника как сумму трёх сторон.

Формула: P = a + b + c

**Параметры**

| Имя | Тип | Описание |
|-----|-----|----------|
| `a` | число | длина первой стороны |
| `b` | число | длина второй стороны |
| `c` | число | длина третьей стороны |

**Возвращаемое значение**

Периметр треугольника.

**Пример**

```python
>>> import triangle
>>> triangle.perimeter(3, 4, 5)
12
```
